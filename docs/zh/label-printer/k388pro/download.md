2. 离线 API 文档为单页 HTML，本地双击即可浏览（含中英切换与 API 检索）。
3. 在线 API 参考见 [API 参考](/zh/label-printer/k388pro/)。
4. 蓝牙外接版本见 [K388Pro 蓝牙版本](/zh/label-printer/k388pro-ble/)。
