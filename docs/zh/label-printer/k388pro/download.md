# 下载和 Demo

K388Pro 打印 SDK **v2.4.3** — **本机 + 蓝牙**统一入口（`UK388PrintLibrary_v2.4.3.jar`）。文件在仓库目录 `downloads/k388pro/`。

## 下载列表

| 文件 | 说明 | 下载 |
|------|------|------|
| `K388Pro_Printer_SDK.zip` | SDK v2.4.3 完整包（`SDK/` JAR、`DemoCode/`、`DemoAPK/`、`Docs/`） | [下载 SDK](https://github.com/UrovoSdkCenter/docs-site/raw/main/downloads/k388pro/K388Pro_Printer_SDK.zip) |
| `k388-printer-sdk-sdk-docs.zip` | 离线 API 文档包（zip；解压后双击 HTML 用浏览器打开） | [下载离线 API 文档](https://github.com/UrovoSdkCenter/docs-site/raw/main/downloads/k388pro/k388-printer-sdk-sdk-docs.zip) |

## 包内结构

| 路径 | 说明 |
|------|------|
| `SDK/UK388PrintLibrary_v2.4.3.jar` | 打印库（本机 + BLE） |
| `DemoCode/K388BlePrinterDemo/` | Demo 工程源码 |
| `DemoAPK/K388BlePrinterDemo_v2.4.3.apk` | 可安装 Demo APK |
| `Docs/k388-printer-2.4.3.html` | 离线 API 文档（与文档 zip 内容一致） |

## 使用说明

1. 解压 `K388Pro_Printer_SDK.zip`。
2. 将 `SDK/UK388PrintLibrary_v2.4.3.jar` 放入工程 `libs/`（或直接参考 `DemoCode/K388BlePrinterDemo`）。
3. 安装 `DemoAPK/K388BlePrinterDemo_v2.4.3.apk`，可验证本机 / 蓝牙打印。
4. 在线 API 参考见 [API 参考](/zh/label-printer/k388pro/)。
