# 下载和 Demo

本页提供 Cradle（DockLib）的 SDK 包与离线 API 文档。文件在仓库目录 `downloads/cradle/`。

## 下载列表

| 文件 | 说明 | 下载 |
|------|------|------|
| `CradleLib_SP35.zip` | Cradle SDK 包（含 AAR / 文档等） | [下载 SDK](https://github.com/UrovoSdkCenter/docs-site/raw/main/downloads/cradle/CradleLib_SP35.zip) |
| `docklib-sdk-docs.zip` | 离线 API 文档包（zip；解压后双击 HTML 用浏览器打开） | [下载离线 API 文档](https://github.com/UrovoSdkCenter/docs-site/raw/main/downloads/cradle/docklib-sdk-docs.zip) |

## 使用说明

1. 解压 SDK zip，按包内说明将 AAR / 模块接入工程。
2. 下载 zip 并解压后，本地双击 HTML 即可浏览。
3. 在线 API 参考见 [API 参考](/zh/cradle/)。
