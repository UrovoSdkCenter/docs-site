# 下载和 Demo

本页提供 POS Printer SDK 包与离线 API 文档。文件在仓库目录 `downloads/pos/`。

## 下载列表

| 文件 | 说明 | 下载 |
|------|------|------|
| `UrovoPrinterSdk_v1.0.6.7z` | POS Printer SDK 包（v1.0.6） | [下载 SDK](https://github.com/UrovoSdkCenter/docs-site/raw/main/downloads/pos/UrovoPrinterSdk_v1.0.6.7z) |
| `urovo-pos-printer-api.zip` | 离线 API 文档包（zip；解压后双击 HTML 用浏览器打开） | [下载离线 API 文档](https://github.com/UrovoSdkCenter/docs-site/raw/main/downloads/pos/urovo-pos-printer-api.zip) |

## 使用说明

1. 解压 SDK 包，按包内说明将 AAR / 模块接入工程。
2. 下载 zip 并解压后，本地双击 HTML 即可浏览。
3. 在线 API 参考见 [API 参考](/zh/printer/pos/)。
