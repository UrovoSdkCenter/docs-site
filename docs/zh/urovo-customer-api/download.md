# 下载和 Demo

本页提供 Urovo 设备 API（USDK Profile Service JAR）的离线 API 文档。文件在仓库目录 `downloads/urovocustomapi/`。

## 下载列表

| 文件 | 说明 | 下载 |
|------|------|------|
| `urovo-custom-api-sdk-docs.zip` | 离线 API 文档包（zip；解压后双击 HTML 用浏览器打开，含完整方法签名与示例） | [下载离线 API 文档](https://github.com/UrovoSdkCenter/docs-site/raw/main/downloads/urovocustomapi/urovo-custom-api-sdk-docs.zip) |

## 使用说明

1. 下载 zip 并解压后，本地双击 HTML 即可用浏览器离线浏览（支持中英文切换与搜索）。
2. 在线 API 参考见 [API 参考](/zh/urovo-customer-api/)。
