# RFID Overview

The native Android RFID SDK is provided as an `.aar` library. It supports all-in-one RFID devices, Sled RFID Bluetooth devices, and Pogopin RFID devices.

## Supported Devices

- All-in-one RFID
- Sled RFID (Bluetooth)
- Pogopin RFID
