# Download & Demo

Offline API documentation for the K388Pro **built-in printer** SDK. Files are under `downloads/k388pro/`.

## Downloads

| File | Description | Download |
|------|-------------|----------|
| `k388-printer-sdk-docs.html` | Offline API docs (open in a browser) | [Download offline API docs](https://github.com/UrovoSdkCenter/docs-site/raw/main/downloads/k388pro/k388-printer-sdk-docs.html) |

## Usage

1. The offline API docs are a single HTML file—open it locally in a browser (ZH/EN switch and API search included).
2. Online API reference: [API Reference](/en/label-printer/k388pro/).
3. Bluetooth version: [K388Pro BLE](/en/label-printer/k388pro-ble/).
