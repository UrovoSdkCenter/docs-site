# RFID 概述

Android 原生 RFID SDK，以 `.aar` 形式提供，适用于一体机 RFID、Sled RFID 蓝牙设备以及 Pogopin RFID 设备。

## 适用设备

- 一体机 RFID
- Sled RFID（蓝牙）
- Pogopin RFID
