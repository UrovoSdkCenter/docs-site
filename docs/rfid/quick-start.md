# Quick Start

## 1. Get the SDK

Download the latest `.aar` from the [Releases page](https://github.com/UrovoSdkCenter/RFID_Android/releases), or follow the repository instructions.

## 2. Add to your project

Put the `.aar` in your module `libs` folder and add:

```groovy
dependencies {
    implementation files('libs/xxx.aar') // replace with the real file name
}
```

## 3. Initialize and call

```kotlin
// Replace with the real SDK APIs
// RfidManager.init(context)
// RfidManager.startInventory { tag -> /* handle tag */ }
```

For a full runnable sample, use the [Demo source](https://github.com/UrovoSdkCenter/RFID_Android).
