# API Reference

Unless noted otherwise, APIs below are on `UPrinterManager`.

| Category | Description |
|----------|-------------|
| [Entry and lifecycle](/label-printer/k388pro/api/init) | Singleton, version, release |
| [Connection and status](/label-printer/k388pro/api/connection) | Connect, disconnect, status listener |
| [Send print data](/label-printer/k388pro/api/print) | `printByData` / `printByText` |
| [Page setup](/label-printer/k388pro/api/page) | Size, rotation, gap, build data |
| [Drawing](/label-printer/k388pro/api/drawing) | Text, graphics, barcodes, images |
| [Print settings](/label-printer/k388pro/api/settings) | Contrast, speed, darkness, etc. |
| [RFID](/label-printer/k388pro/api/rfid) | Read/write and power |
| [Firmware](/label-printer/k388pro/api/firmware) | Version and upgrade |

Exception class: `com.urovo.printer.exception.PrinterException`
