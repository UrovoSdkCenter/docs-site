    1、Overview

    1.1、Introduction

    Urovo Printer SDK (urovoPrinterLib) is a thermal printing library for UROVO POS devices with built-in printers. It supports text, barcodes, QR codes, images, HTML, and label printing. The main entry class is com.urovo.sdk.print.PrinterProviderImpl.

    ItemDetail
    Version1.0.6
    PlatformAndroid
    Min SDKAPI 21 (Android 5.0)
    Target SDKAPI 33
    Max paper width384 dots (~58 mm thermal paper)

    1.2、Version history

    This document corresponds to SDK release 1.0.6 (urovoPrinterLib_v1.0.6_release.aar).

    1.3、Key features

    • Thermal receipt printing: formatted text, left/right/center columns, feed and separator lines
    • Barcodes and QR codes with alignment and size options
    • Image printing: byte-array bitmaps and image-with-text layouts
    • HTML printing: render HTML to bitmap then print
    • Label mode: positioning, continuous feed, end feed (device-dependent)
    • Printer status: out of paper, overheat, low voltage, busy, etc.

    1.4、Use cases

    • POS transaction receipts, retail and delivery tickets
    • Logistics labels (when the device supports label mode)
    • App-drawn UI (Canvas/PaintView) exported as bitmap
    • Web or rich text rendered to HTML then printed

    1.5、Requirements

    ItemRequirement
    DeviceUROVO POS terminal with built-in thermal printer
    AndroidminSdk 21+
    IntegrationLocal AAR (libs/ or flatDir)
    StorageREAD/WRITE_EXTERNAL_STORAGE; request MANAGE_EXTERNAL_STORAGE on Android 11+ when needed for custom TTF paths
    DependenciesBundled platform_sdk JAR and default font assets/simsun.ttc inside the AAR

    2.2、Project setup

    Copy urovoPrinterLib_v1.0.6_release.aar into your app module libs/ folder.

    settings.gradle (flatDir example):

    gradle
    dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        flatDir { dirs 'libs' }
    }
}

    app/build.gradle:

    gradle
    dependencies {
    implementation(name: 'urovoPrinterLib_v1.0.6_release', ext: 'aar')
}

    Permissions

    Declare in AndroidManifest.xml and request at runtime per target Android version:

    2.3、Initialization

    Recommended lifecycle: getInstance → initPrint → add content → startPrint → close. Call close() after each print job and initPrint() before the next. Check getStatus() before printing.

    Authentication: None (built-in printer, no API keys).

    3、Quick Start

    1. PrinterProviderImpl.getInstance(context) — obtain instance
    2. initPrint() — initialize printer
    3. getStatus() — confirm status is OK (0x00 / PrintStatus.ERROR_NONE)
    4. Call addText / addImage etc. to build content
    5. feedLine() — feed paper as needed
    6. startPrint() — submit print; 0x00 means success
    7. close() — release printer

    5、Examples

    Samples from Demo MainActivity.java (com.urovo.print.test). Run printing on a background thread.

    5.1、Query printer status

    java
    PrinterProviderImpl mPrintManager = PrinterProviderImpl.getInstance(context);
mPrintManager.initPrint();
int status = mPrintManager.getStatus();
// status == 0 means printer is ready
mPrintManager.close();

    Notes: Call initPrint() before query and close() when done; check getStatus() before printing.

    5.2、Full receipt print

    java
    PrinterProviderImpl mPrintManager = PrinterProviderImpl.getInstance(context);

new Thread(() -> {
    try {
        mPrintManager.initPrint();
        if (mPrintManager.getStatus() != 0) return;

        mPrintManager.setGray(0);
        mPrintManager.setSpeed(15);

        Bundle format = new Bundle();
        byte[] imageData = getBitmapBytes(bitmap);
        format.putInt(PrintFormat.ALIGN, PrintFormat.ALIGN_CENTER);
        format.putInt(PrintFormat.WIDTH, 196);
        format.putInt(PrintFormat.HEIGHT, 58);
        mPrintManager.addImage(format, imageData);

        format = new Bundle();
        format.putInt(PrintFormat.FONT, PrintFormat.FONT_NORMAL);
        format.putInt(PrintFormat.ALIGN, PrintFormat.ALIGN_CENTER);
        format.putBoolean(PrintFormat.FONTBOLD, true);
        mPrintManager.addText(format, "CENTER");

        format = new Bundle();
        format.putInt(PrintFormat.FONT, PrintFormat.FONT_NORMAL);
        mPrintManager.addTextLeft_Right(format, "Item", "$15");
        mPrintManager.addTextLeft_Center_Right(format, "Item", "16", "$15");

        format = new Bundle();
        format.putInt(PrintFormat.ALIGN, PrintFormat.ALIGN_CENTER);
        format.putInt(PrintFormat.WIDTH, 300);
        format.putInt(PrintFormat.HEIGHT, 100);
        mPrintManager.addBarCode(format, "33333333333333");
        mPrintManager.feedLine(3);

        format = new Bundle();
        format.putInt(PrintFormat.ALIGN, PrintFormat.ALIGN_CENTER);
        format.putInt(PrintFormat.EXHEIGHT, 100);
        mPrintManager.addQrCode(format, "222222222222222222222");

        mPrintManager.feedLine(-1);
        int iRet = mPrintManager.startPrint();
        mPrintManager.close();
    } catch (Exception e) {
        e.printStackTrace();
    }
}).start();

    Notes: startPrint() blocks; use a worker thread; keep image width ≤ 380.

    5.3、HTML print

    java
    mPrintManager.initPrint();
if (mPrintManager.getStatus() != 0) return;

mPrintManager.setGray(6);
String content = htmlConvertToString(context, "html_text_document.txt");

    5.4、Label print

    java
    mPrintManager.initPrint();
if (mPrintManager.getStatus() != 0) return;
if (!mPrintManager.supportLabelPrint()) return;
if (!mPrintManager.setPrinterMode(true)) return;

mPrintManager.setLabelFeed(PrinterLabelState.PRN_LABEL_LOCATION);
mPrintManager.addBlankLine(topMargin);

byte[] imageData = getBitmapBytes(labelBitmap);
Bundle format = new Bundle();
format.putInt(PrintFormat.WIDTH, labelBitmap.getWidth());
format.putInt(PrintFormat.HEIGHT, labelBitmap.getHeight());
mPrintManager.addImage(format, imageData);

mPrintManager.feedLine(-1);
mPrintManager.startPrint();
mPrintManager.setLabelFeed(PrinterLabelState.PRN_LABEL_END);
mPrintManager.close();

    Notes: Check supportLabelPrint() first; call setLabelFeed(PRN_LABEL_LOCATION) before content; call PRN_LABEL_END after print.

    6、Notes & FAQ

    6.1、Notes

    • Lifecycle: Call close() after each job; call initPrint() before the next to avoid resource leaks.
    • Threading: startPrint() is synchronous; avoid long prints on the main thread.
    • Paper width: Do not exceed 384 dots; image width ≤ 380 recommended.
    • Fonts: Custom TTF paths must be readable; grant storage permissions.

    6.2、FAQ

    Q: What must I call before printing?

    A: getInstance() → initPrint() → check getStatus() → add content → startPrint() → close().

    Q: What if startPrint returns non-zero?

    A: Map the code via PrintStatus; handle out-of-paper, overheat, or low voltage before retrying.

    Q: Is HTML printing supported?

    A: Yes, via addHtml(); complex CSS may vary by device.

    Q: How do I switch label vs receipt mode?

    A: Use supportLabelPrint(), then setPrinterMode(true/false) with setLabelFeed() for label feed control.

    1、概述

    1.1、简介

    Urovo Printer SDK（urovoPrinterLib）面向 UROVO POS 终端内置热敏打印机，提供文本、条码、二维码、图片、HTML 及标签纸打印能力。核心入口类为 com.urovo.sdk.print.PrinterProviderImpl。

    项目说明
    版本1.0.6
    平台Android
    最低 SDKAPI 21（Android 5.0）
    目标 SDKAPI 33
    最大纸宽384 点（约 58mm 热敏纸）

    1.2、版本变更

    当前文档对应 SDK 1.0.6 发布包（urovoPrinterLib_v1.0.6_release.aar）。

    1.3、主要能力

    • 热敏小票打印：多格式文本、左右/三列对齐、走纸与分隔线
    • 条码与二维码：一维码、QR Code，可配置对齐与尺寸
    • 图片打印：字节数组位图、图文混排
    • HTML 打印：将 HTML 内容渲染为位图后输出
    • 标签纸模式：定位、连续打印、结束走纸（需设备支持）
    • 打印机状态查询：缺纸、过热、低压、忙等错误码

    1.4、适用场景

    • POS 交易凭条、外卖/零售小票
    • 物流面单、标签纸打印（设备支持时）
    • 应用自绘界面（Canvas/PaintView）转 Bitmap 打印
    • Web 或富文本内容转 HTML 后打印

    1.5、环境要求

    项要求
    设备UROVO POS 终端（内置热敏打印机）
    AndroidminSdk 21+
    集成方式本地 AAR（libs/ 或 flatDir）
    存储权限READ/WRITE_EXTERNAL_STORAGE；Android 11+ 按需申请 MANAGE_EXTERNAL_STORAGE（自定义 TTF 字体路径等）
    依赖AAR 内已打包 platform_sdk JAR 及默认字体 assets/simsun.ttc

    5、示例

    以下示例摘自 Demo 工程 MainActivity.java（com.urovo.print.test）。打印逻辑在后台线程执行，避免阻塞 UI。

    5.1、查询打印机状态

    java
    PrinterProviderImpl mPrintManager = PrinterProviderImpl.getInstance(context);
mPrintManager.initPrint();
int status = mPrintManager.getStatus();
// status == 0 表示打印机正常
mPrintManager.close();

    要点： 每次查询前需 initPrint()，结束后 close()；打印前建议同样检查 getStatus()。

    5.2、综合小票打印

    java
    PrinterProviderImpl mPrintManager = PrinterProviderImpl.getInstance(context);

new Thread(() -> {
    try {
        mPrintManager.initPrint();
        if (mPrintManager.getStatus() != 0) return;

        mPrintManager.setGray(0);
        mPrintManager.setSpeed(15);

        Bundle format = new Bundle();
        byte[] imageData = getBitmapBytes(bitmap);
        format.putInt(PrintFormat.ALIGN, PrintFormat.ALIGN_CENTER);
        format.putInt(PrintFormat.WIDTH, 196);
        format.putInt(PrintFormat.HEIGHT, 58);
        mPrintManager.addImage(format, imageData);

        format = new Bundle();
        format.putInt(PrintFormat.FONT, PrintFormat.FONT_NORMAL);
        format.putInt(PrintFormat.ALIGN, PrintFormat.ALIGN_CENTER);
        format.putBoolean(PrintFormat.FONTBOLD, true);
        mPrintManager.addText(format, "CENTER");

        format = new Bundle();
        format.putInt(PrintFormat.FONT, PrintFormat.FONT_NORMAL);
        mPrintManager.addTextLeft_Right(format, "健力宝", "15元");
        mPrintManager.addTextLeft_Center_Right(format, "健力宝", "16", "15元");

        format = new Bundle();
        format.putInt(PrintFormat.ALIGN, PrintFormat.ALIGN_CENTER);
        format.putInt(PrintFormat.WIDTH, 300);
        format.putInt(PrintFormat.HEIGHT, 100);
        mPrintManager.addBarCode(format, "33333333333333");
        mPrintManager.feedLine(3);

        format = new Bundle();
        format.putInt(PrintFormat.ALIGN, PrintFormat.ALIGN_CENTER);
        format.putInt(PrintFormat.EXHEIGHT, 100);
        mPrintManager.addQrCode(format, "222222222222222222222");

        mPrintManager.feedLine(-1);
        int iRet = mPrintManager.startPrint();
        mPrintManager.close();
    } catch (Exception e) {
        e.printStackTrace();
    }
}).start();

    要点： startPrint() 为同步阻塞调用，须在后台线程执行；图片 width 建议 ≤ 380。

    5.4、标签打印

    java
    mPrintManager.initPrint();
if (mPrintManager.getStatus() != 0) return;
if (!mPrintManager.supportLabelPrint()) return;
if (!mPrintManager.setPrinterMode(true)) return;

mPrintManager.setLabelFeed(PrinterLabelState.PRN_LABEL_LOCATION);
mPrintManager.addBlankLine(topMargin);

byte[] imageData = getBitmapBytes(labelBitmap);
Bundle format = new Bundle();
format.putInt(PrintFormat.WIDTH, labelBitmap.getWidth());
format.putInt(PrintFormat.HEIGHT, labelBitmap.getHeight());
mPrintManager.addImage(format, imageData);

mPrintManager.feedLine(-1);
mPrintManager.startPrint();
mPrintManager.setLabelFeed(PrinterLabelState.PRN_LABEL_END);
mPrintManager.close();

    要点： 先 supportLabelPrint() 判断能力；setLabelFeed(PRN_LABEL_LOCATION) 在添加内容前调用；打印结束后调用 PRN_LABEL_END。

    6、注意事项与 FAQ

    6.1、注意事项

    • 生命周期：每次打印完成后 close()，下次再 initPrint()，避免资源占用与状态错乱。
    • 线程：startPrint() 为同步调用，不宜在主线程执行长时间打印。
    • 纸宽：内容宽度勿超过 384 点；图片 width 建议 ≤ 380。
    • 字体：自定义 TTF 需可读路径，并申请存储权限。

    6.2、FAQ

    Q: 打印前必须调用哪些方法？

    A: getInstance() → initPrint() → 检查 getStatus() → 添加内容 → startPrint() → close()。

    Q: startPrint 返回非 0 怎么办？

    A: 对照 PrintStatus 错误码处理；缺纸/过热/低压需人工干预后重试。

    Q: 是否支持 HTML 打印？

    A: 支持，使用 addHtml()；复杂 CSS 渲染效果以实机为准。

    Q: 标签纸与普通小票如何切换？

    A: supportLabelPrint() 判断能力后，setPrinterMode(true/false) 切换，并配合 setLabelFeed() 控制走纸。
